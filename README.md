# Nazmul.dev — Developer Portfolio

A modern, responsive developer portfolio built to showcase my skills, projects, education, and journey as a developer.

## Live Link: https://new-portfolio-black-six.vercel.app/

## 🚀 Overview

Welcome to my personal portfolio! This website highlights my technical skills, featured projects, educational background, and development experience. It is designed with a clean, modern interface, a dark theme, cyan accents, and smooth animations to provide a polished browsing experience.

## ✨ Features

- **Responsive Design** — Optimized for desktop, tablet, and mobile devices.
- **Modern UI** — Clean dark theme with cyan accents.
- **Hero Section** — Introduction, designation, and social links.
- **About Me** — Information about my background and development journey.
- **Skills Section** — Highlights my technical skills and technologies.
- **Education Section** — Showcases my academic background.
- **Projects Showcase** — Displays featured projects with descriptions and technology stacks.
- **Project Details** — Dedicated pages for individual projects.
- **Resume Download** — Allows visitors to view or download my resume.
- **Contact Section** — Provides ways to get in touch.
- **Smooth Animations** — Subtle transitions and interactive hover effects.

## 💻 Getting Started

Follow these steps to run the project locally.

### Prerequisites

Make sure you have installed:

- Node.js
- npm
- Git

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/Nazmul-07/New-Portfolio.git
```

**2. Navigate to the project directory**

```bash
cd New-Portfolio
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

To create an optimized production build:

```bash
npm run build
```

To run the production build locally:

```bash
npm start
```
